# Python Based Projects From Beginner to Advanced

A collection of small Python projects for learning and practicing programming fundamentals through interactive command-line applications.

---

## Beginner

These projects are perfect for those new to Python and programming fundamentals.

### #1 - Quiz Game

A simple command-line quiz application that tests general knowledge. The script presents questions, accepts user input, and reports the number of correct and incorrect answers.

**Implemented file:** [beginner/quiz_game.py](beginner/quiz_game.py)

### #2 - Rock, Paper, Scissors

A command-line game where the user competes against the computer. The script uses random selection for the computer's choice and conditional logic to determine the winner.

**Implemented file:** [beginner/rock_paper_scissors.py](beginner/rock_paper_scissors.py)
